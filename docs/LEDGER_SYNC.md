# 台帳の自動登録(予約リクエスト → Google スプレッドシート)

サイトのフォームから予約リクエストが届くと、Cloudflare Worker が台帳の
Apps Script(ウェブアプリ)に内容を1件 POST し、スクリプトが「予約一覧」と
「手配・体験詳細」に同じIDで1行ずつ追加します。メール配送(自動返信・社内通知・
フォローアップ)が済んでから送るので、台帳には「自動返信送信済み」などの状態も入ります。

送る側のコードは `lib/ledger.ts`、受ける側は `docs/ledger-apps-script.gs`。

## 設置手順(1回だけ、10分)

1. 台帳のスプレッドシートを開く → メニュー「拡張機能」→「Apps Script」。
2. 開いたエディタの `コード.gs` の中身を全部消し、`docs/ledger-apps-script.gs` の内容を貼り付けて保存(Ctrl+S)。
3. 動作確認: 上の関数選択で `testAppend` を選び「実行」。初回は権限の許可画面が出るので、自分の Google アカウントで「許可」。「予約一覧」の最終行に TEST 行が1件入れば OK(確認後、その行は削除してよい)。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 説明: 台帳自動登録
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**(URL を知っている Worker だけが呼びます。URL は推測できない長い文字列です)
   → 「デプロイ」。表示される **ウェブアプリの URL**(`https://script.google.com/macros/s/…/exec`)をコピー。
5. その URL を Claude に渡す(チャットに貼るだけでよい)。`vite.config.ts` の `vars` に `LEDGER_WEBHOOK_URL` として入れて公開します。
   - 自分で設定する場合: Cloudflare ダッシュボード → Workers & Pages → kamehame-japan → Settings → Variables and Secrets → 「Add」→ 名前 `LEDGER_WEBHOOK_URL`、値に URL → Secret で保存。デプロイのたびに消えないよう、Secret を選ぶ。

スクリプトを直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」で URL を変えずに更新できます。

## 台帳に入る内容

| 予約一覧 | 値 |
|---|---|
| 予約・案件ID | `KJ-体験日(YYMMDD)-連番`。体験日がない問い合わせは `KJ-INQ-受付日-連番` |
| 予約状況 | 受付(取引先の問い合わせは「対応不要」) |
| 支払い状況 | 入金未確認 |
| 次のアクション / 対応期限 | パートナーに空き確認 → 提案メール / 受付日の翌日 |
| 受付日・最終連絡日 | 受付日(自動返信が最終連絡) |
| サイト概算 | フォーム送信時にサイトが示した金額 |
| 顧客の無料取消期限 | 体験日の7日前 18:00(体験ごとの規定があればそれに従う) |
| 確認メモ | 自動登録である旨と、自動返信・フォローアップの送信状態 |

| 手配・体験詳細 | 値 |
|---|---|
| エリア / 体験名 / 出発時刻 / 送迎場所 / 人数 | フォームの内容(送迎場所は日本語訳があれば訳) |
| 希望・アレルギー等 | 備考の日本語訳と原文、ゴルフ経験、通訳 |
| レンタル・持参品 | 各ゴルファーのレンタル・利き手、クラブの希望(日本語訳) |
| 追加オプション / パートナー / 手配状況 | オプション / Rion Japan(ゴルフ) / 未着手 |
| キャンセル条件 | 顧客側の無料取消期限(サイト規定) |
| 手配メモ | 料金メモ(価格表の読み) |

「見込粗利（自動）」「お客様名（自動）」の数式列には書き込みません。提示額・入金・仕入・決済リンク・確認メールURL は手入力のままです。

## 失敗したとき

- Worker 側で6秒以内に応答がない、または URL が未設定なら、台帳には入りません(メールと Slack は通常どおり)。Cloudflare のログに `ledger:` で始まる行が出ます。
- Apps Script 側のエラーは「Apps Script」→「実行数」で見られます。シート名を変えた場合は `.gs` の `SHEET_MAIN` / `SHEET_DETAIL` も合わせてください。
