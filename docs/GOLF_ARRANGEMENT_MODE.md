# ゴルフページの「手配サービス」モード（2026-10-17、一時的）

運営の仕組みが整うまでの暫定表示です。切り替えは1か所で、元のプライベートゴルフ（パッケージ）のコードは
そのまま残っています。

## 切り替え方法

`lib/golf-prices.ts` の `GOLF_MODE` を変えて main に push するだけです。

| 値 | ページ |
|---|---|
| `"arrangement"`（現在） | 日本のゴルフ場手配サービス。手配料は1組の金額で、1名目 ¥15,000（`GOLF_ARRANGEMENT_FEE_JPY`）＋2名目以降1名 ¥5,000（`GOLF_ARRANGEMENT_EXTRA_JPY`、税込。`golfArrangementFee(n)`。2名 ¥20,000・3名 ¥25,000・4名 ¥30,000。オーナー 2026-10-24。10-17〜10-23 は1名 ¥15,000 の定額だった）、1〜12名（5名以上は見積。`GOLF_FIXED_FEE_MAX`=4、`GOLF_MAX_GOLFERS`=12、オーナー 2026-10-23）、現地集合、プレー代・カート・レンタル・昼食は現地精算、送迎は提携会社を紹介して直接契約、アシスタント同行は別途見積。表示通貨は他ページと同じく円がデフォルト（2026-10-24 オーナー指示。10-17〜10-24 はドル表示を優先していた。ヘッダーの切替でドルも選べる）。 |
| `"package"` | 2026-10-16 までのプライベートゴルフ・パッケージ（送迎・プレー代・カート・レンタル・昼食・アシスタント込み、2〜4名のグループ料金、クラブ持参 −¥5,000）。 |

パッケージ版のコミットには git タグ `golf-package-2026-10-16` を付けています。文言は5言語とも
各カタログ（`lib/catalog*.ts`）に残っており、手配サービスの文言は `lib/golf-arrangement-copy.ts` に
まとめてあります（`applyGolfArrangement` がモード有効時だけ上書き）。

## モードで変わるもの

- 料金: `golfTiers` / `golfPackagePrice` が `golfArrangementFee(人数)`（基本料＋追加料×(人数−1)）を返す。表示は1組の手配料を先頭に、内訳「¥15,000 + ¥5,000 × 追加n名」を添える（`golfFeeBreakdown`、文言は `options.feeBase` / `feeBreakdown` / `feeRule`）。希望コース指定も同じ手配料（個別見積にしない）。
  クラブ持参の値引きは適用しない。
- フォーム: 送迎都県・ホテル必須の欄を外し「滞在先（任意）」のみ。「希望の開始時刻」はティータイム。
  「当日の英語対応アシスタント」の選択を追加（`assistant` として受付通知に「アシスタント同行」行で表示）。
  「ゴルフ場までの送迎」の選択を追加（`transfer`: 不要／提携会社の紹介を希望／相談したい。注釈「送迎は当社のサービスには含まれず、ご希望の場合は提携会社に直接おつなぎする」。受付通知に「送迎(提携会社紹介)」行、お客様向け受付メールの要約にも表示）。
- 含まれるものの一覧: 10項目。当社が手配できるもの（予約・レンタルクラブ・シューズ・専用車送迎＝対応会社の紹介・
  英語アシスタント＝オプション・カート・ロッカー・浴場・税）と、ウェアのみ対象外。ドライバーと昼食のカードは表示しない。
- 送迎セクション: 「行き方は、お好みで」（現地集合／提携会社の専用車／電車とタクシー）。
- 受付メール・サンクス画面・決済完了画面・特商法ページの文言: `golfProcessCopy()` 経由で同じ切り替え。
- 構造化データの価格: 手配料の範囲。

## 変わらないもの・注意

- 手配モードでは旧パッケージのApps Script自動化をWorker側で遮断する（URL・TOKENが設定済みでも対象外）。
  新しい写真付き決済案内はコース提案を確認して個別に作成する。運用・切戻し手順は `GOLF_MAIL_MODES.md`。
- 手配料の返金は `lib/golf-arrangement-policy.ts` の進行段階別規定（2026-10-19）。日数別の旧取消表は手配モードでは表示しない。
- 条件合意・決済の後に具体的なコース調査を開始し、提案承認後に予約する。問い合わせ無料と有料調査を区別する。
- 2名以上の送迎付き案は担当者の個別メール下書きだけに含める。公開ページは手配サービスのまま。運用は `GOLF_MAIL_MODES.md` を参照。
- `tests/rendered-html.test.mjs` のゴルフのテストはモードごとに分かれている。

## 指定レンタルクラブ（オプション、2026-10-25、確認用プレビューのみ）

ゴルフ場のレンタルはメーカー・モデルを選べないため、提携先のレンタル業者から選んだセットをゴルフ場へ届けるオプション。
`lib/golf-club-rental.ts` に料金（1セット ¥15,000 税込、`GOLF_CLUB_RENTAL_JPY`）、締切（プレー7日前、`GOLF_CLUB_RENTAL_CUTOFF_DAYS`）、
代表13セット（画像は `public/images/golf-clubs/`、提携先の許可を得て転載。提携先名はページに出さない）、5言語の文言。

- 表示は `ClubRentalProvider`（`components/site/club-rental-context.tsx`）と `VariantDetail` の `clubRental` で切り替える。本番のゴルフページでは無効のまま。
  確認用: `/previews/golf-club-rental-7c3e9a51b2/?lang=en`（noindex、一覧・サイトマップ外。`lang` は ja/es/fr/zh-tw も可）。
- フォーム: ゴルファーごとのレンタル選択に「指定モデル（+¥15,000）」が加わり、セット選択のシートが開く。`rental_keys` は `designated:<利き手>:<セットID>`。
  サーバーはセットIDをカタログと照合し（不明なIDは400）、概算に1セット¥15,000×人数を加算、`priceNote` に `club-rental-2026-10-25` を記録。通知・Slackに「指定レンタル」行。
- 選択パネル・固定バー・フォーム要約は「手配料 ¥20,000 + 指定レンタル ¥15,000 × 1 = ¥35,000」の形。
- 規約: 提案承認後・7日前までに発注、発送（約3日前）までは変更・取消無料、発送後は返金なし（天候クローズ時も）。FAQに1問追加。
- 未対応（本番化の前に）: 決済（手配料＋レンタルを1回で払うStripe Checkout、オーナー決定 2026-10-25）、提携先への発注フロー、取消規定の社内手順。
