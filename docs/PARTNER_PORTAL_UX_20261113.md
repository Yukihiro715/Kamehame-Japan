# パートナー管理画面 UI/UX 更新（2026-11-13）

## 目的

パートナーが体験を選び、紹介・予約相談を行い、進捗と紹介料を確認しやすくする。事業用ダッシュボードの余白・情報の優先順位・左ナビゲーションを参考に、KAMEHAMEのオレンジを基調にした。

## 主な変更

- `/hotel/` のみに `pt-partner` テーマを適用。PCは左メニュー、スマホは開閉メニュー。キーボードフォーカス、本文スキップ、Escapeでのメニュー終了に対応。
- サマリーは重要な4指標と「体験を探す」「予約・相談を登録」「QR・紹介リンクを共有」を先頭に配置。カードは詳細ページに遷移する。予約作成日による指標と実施日による指標、全期間の未払・見込を区別。
- 体験一覧は写真付きカード。日英の体験名・エリアを検索し、エリア、予約方式、紹介料対象で絞り込める。料金、紹介料率、紹介料の目安を表示。詳細条件は展開して確認。
- 案件一覧はサーバー検索と20件単位のページ送り。顧客名・番号、状態、次の対応、見積もり、担当、更新日時をカードで表示。
- 紹介予約は25件単位のページ送り。スマホでは予約カードを開いて金額・保留理由を読む。サマリーから予約日フィルターを引き継ぐ。
- 案件登録は体験を明示選択する。体験一覧から遷移した場合は対象体験を選択済みにする。商品・相談種別の変更で商品固有の入力をクリアする。
- 紹介リンク・見積もりリンクはコピー成功／失敗を表示。リンク発行中は重複操作を抑制し、失敗を画面に表示。
- APIの拠点機能・メンバー権限に合わせて導線を表示。拠点変更時は子画面を再マウントし、前の拠点のフォーム・取得データを残さない。サーバーの認証・認可は引き続き最終判定を行う。

## 対象外

紹介料・精算の計算、決済処理、データベース、メール送信条件は変更していない。新たなメンバー権限も付与していない。

## ブラウザー確認項目

1. 拠点切替で前の拠点の値が消え、権限のない機能への導線が表示されない。
2. 体験の検索・エリア・方式・対象フィルターを組み合わせ、0件と条件クリアを確認。
3. 案件・紹介予約の次ページ、前ページ、検索後の1ページ目復帰を確認。
4. 体験から案件登録への商品引継ぎ、未選択時の登録防止、商品切替時の追加項目クリアを確認。
5. 紹介リンク・見積もりURLのコピー成功と、クリップボード利用不可時の案内を確認。
6. スマホのメニュー、長い顧客名・メール・URL・金額、精算書の印刷表示を確認。
