# 計測の設定(GTM / GA4 / Search Console / Google広告)

サイト側に入っているのは **GTMのコンテナ1つだけ**(`GTM-57CCF3MQ`)。
GA4も広告タグもGTMの中で設定するので、**タグを増やすたびにサイトを更新する必要はありません**。

- 設置場所: `app/layout.tsx`(全ページの `<head>` 直下 + `<body>` 直後のnoscript)
- コンテナID: `lib/analytics.ts` の `GTM_ID`

## サイトから送っているイベント

| イベント名 | 発火するとき | 一緒に送られる値 |
| --- | --- | --- |
| `enquiry_sent` | 問い合わせフォームの送信が**成功**したとき | `enquiry_kind`(guest / trade)、`experience`(体験のslug)、`experience_title`、`language`、`party_size` |

「送信ボタンを押した」ではなく「サーバーが受け取った」時点で送っています。
エラーで送れなかったものは計測されません。

## 1. GA4(まずこれ)

1. https://analytics.google.com/ → 管理 → **アカウントを作成**(例:Prosent Inc.)
2. プロパティを作成:プロパティ名「KAMEHAME JAPAN」、**レポートのタイムゾーン=日本**、**通貨=日本円**
3. 業種「旅行」、ビジネスの規模「小規模」
4. データストリーム → **ウェブ** → URL `https://kamehame-japan.com`、ストリーム名「本番サイト」
   - **拡張計測機能はオンのまま**(スクロール・外部リンククリック・ファイルDLを自動で取ります)
5. 表示された **測定ID(`G-` で始まる)** をコピー

### GTM側の設定

1. https://tagmanager.google.com/ → コンテナ `GTM-57CCF3MQ`
2. 左「タグ」→ 新規 → タグの種類 **Google タグ**
   - タグID: さっきの `G-XXXXXXX`
   - トリガー: **Initialization - All Pages**
   - 名前「GA4 - 基本」→ 保存
3. もう1つタグを作る(問い合わせの計測):
   - タグの種類 **GA4 イベント**
   - 設定タグ: 上で作った「GA4 - 基本」
   - イベント名: `generate_lead`
   - イベントパラメータ:
     | パラメータ名 | 値 |
     | --- | --- |
     | `experience` | `{{DLV - experience}}` |
     | `enquiry_kind` | `{{DLV - enquiry_kind}}` |
     | `language` | `{{DLV - language}}` |
   - トリガー: 新規 → **カスタムイベント** → イベント名 `enquiry_sent` → 名前「問い合わせ送信」
   - 名前「GA4 - 問い合わせ送信」→ 保存
4. 変数(上の `{{DLV - ...}}`)を作る:
   左「変数」→ ユーザー定義変数 → 新規 → **データレイヤーの変数**
   - 変数名 `DLV - experience` / データレイヤーの変数名 `experience`
   - 同様に `enquiry_kind`、`language`、`party_size` も作る
5. 右上 **プレビュー** → `https://kamehame-japan.com` を開く → フォームを1件送ってみて
   `enquiry_sent` が光るか確認 → 問題なければ **公開**
6. GA4に戻り 管理 → **キーイベント**(旧コンバージョン)→ `generate_lead` を**キーイベントとしてマーク**
   ※イベントが1回も届いていないと一覧に出ません。テスト送信を1件してから設定してください。

## 2. Search Console

1. https://search.google.com/search-console → プロパティを追加
2. **「ドメイン」** を選ぶ(URLプレフィックスではなく)→ `kamehame-japan.com`
   - www も http も全部まとめて計測できます
3. 表示された **TXTレコード**をコピー
4. Cloudflare → `kamehame-japan.com` → **DNS** → レコードを追加
   - タイプ `TXT` / 名前 `@` / 内容 = コピーしたTXT値 → 保存
5. Search Consoleに戻って **確認**(数分で通ります)
6. 確認できたら:
   - 左「サイトマップ」→ `sitemap.xml` を送信(URLは既に設置済み)
   - 左「設定」→「所有者とユーザー」で必要な人を追加
7. 表示されるまで数日かかります。最初に見るのは
   **「ページ」→ インデックス登録されたページ数**と、**「検索結果」→ クエリ**です

> GTMでも所有権確認はできますが、**ドメイン確認のほうが強い**ので上の方法を推奨します。

## 3. Google広告

1. https://ads.google.com/ → アカウント作成(**「エキスパートモード」に切り替える**。
   スマートモードだと細かい設定ができません)
2. 請求先情報を登録(住所はProsent Inc.の登記住所)
3. **GA4とリンク**: 広告の 管理 → リンク → **Google アナリティクス(GA4)** → 上で作ったプロパティをリンク
4. コンバージョンの設定(どちらか一方)
   - **おすすめ:GA4のキーイベントをインポート**
     広告 → 目標 → コンバージョン → 新しいコンバージョンアクション → **インポート** →
     GA4 → `generate_lead` を選択
   - もしくは GTMに「Google広告のコンバージョントラッキング」タグを追加し、
     トリガーを `enquiry_sent` にする(コンバージョンIDとラベルは広告の画面で発行)
5. **コンバージョン値**: いまは問い合わせ止まりなので、1件あたりの想定価値を入れておくと
   後で入札最適化に効きます(例:問い合わせ→成約率が3割、粗利3万円なら 1万円)
6. 最初のキャンペーンは **検索 + 英語圏** から。予算は日1,000〜2,000円で十分様子が見られます
   - 地域: アメリカ・オーストラリア・イギリス・シンガポールなど、実際に来そうな国
   - 言語: 英語
   - キーワード例: `geisha experience kyoto` / `maiko dinner kyoto` /
     `private geisha dinner` / `kyoto cultural experience`
   - 除外キーワード: `free` `cheap` `costume` `rental`(舞妓変身体験と混ざるため)

---

## 4. 設定の順番

1. GA4プロパティを作る → 測定ID取得
2. GTMでGA4タグ2つ + 変数を作る → プレビューで確認 → 公開
3. フォームからテスト送信を1件 → GA4のリアルタイムで `enquiry_sent` / `generate_lead` を確認
4. GA4でキーイベントに設定
5. Search Console(ドメイン確認 + サイトマップ送信)
6. Google広告(GA4リンク → コンバージョンをインポート)

**広告を出す前に必ず1〜4を終わらせてください。**
計測のないまま出稿すると、何が効いたか分からないまま予算だけ消えます。
