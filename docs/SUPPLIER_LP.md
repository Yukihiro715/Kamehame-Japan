# 体験事業者向け募集LP

- LP: https://kamehame-japan.com/partners-lp/
- 相談後に案内する詳細登録フォーム: https://kamehame-japan.com/partners-lp/register/
- 既存の `/partner/` 管理画面と `/partners/` ページは維持。

## 受付・審査の流れ

相談・詳細登録のどちらも `/api/supplier` で検証し、既存の `RESEND_API_KEY` と `CONTACT_TO`（任意で `ARCHIVE_TO`）を使用して担当者へメール通知する。設定がない場合・送信サービスが失敗した場合は、完了を表示せず再送とメール連絡先を案内する。送信時には受付番号、同意と登録時の条件バージョンを含める。Resendの冪等キーで短時間の再送重複を抑制する。データの受付記録は通知先メールボックスで保管する。新しい公開DBや自動掲載は作成しない。

1. 担当者が「掲載のご相談」通知へ返信する。
2. 掲載を希望する事業者に上記登録URLを案内する（通知本文にもURLを記載）。相談直後の登録リンク自動配信・自動返信は行わない。
3. 「体験情報の登録・審査待ち」の通知で体験情報・卸価格を確認する。
4. 審査、販売・支払条件の合意、原稿翻訳・確認を経て、既存の掲載運用で公開する。

登録フォームは案内メールから開く公開URLで、認証付きではない。検索エンジン向けにnoindexを設定し、LPやサイトマップには登録フォームへのリンクを掲載しない。提出した連絡先や卸価格をページへ公開しない。任意の下書き保存はブラウザ内に限る。

## 検証

`node --test tests/supplier-enquiry.test.mjs` で入力・同意・価格・URL検証、担当者のみへの通知、再送キー、送信失敗、Origin制限、スパム対策をモックで確認する。実メールを送るテストは実施しない。

## 写真・マーク

承認済みLPプレビューから画像とサービスマークを移植。ホテルの写真は説明用の生成イメージで、実在の提携先の紹介ではない。各ブランドは販促接点の説明であり提携表明ではない。
